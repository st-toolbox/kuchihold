# kuchihold

言語聴覚療法（ST）向け **口腔運動ミラートレーニング支援アプリ** のプロトタイプ。

インカメラの自分の口元を**ブレなく拡大表示**し、その上に**目標**（手書き・スタンプ・
目標の口形＝シャドウ・開口度の目標値）を重ねて、鏡を見ながら口の運動訓練を行えます。
指導者が目標を設定する **ST指導モード**と、患者が一人で行う **自主練習モード**、
**患者ごと（管理番号）の記録**に対応します。

> 企画の詳細・背景・ロードマップは [`proposal.md`](./proposal.md) を参照してください。

## 主な機能

- 顔ロック座標系＋平滑化による**口元の安定拡大表示**（鏡表示／傾き補正／ズーム調整）
- **手書き・スタンプ**で目標を描き、顔に追従させる
- **シャドウ目標**：目標到達時の口形を撮影し、半透明の目標として重ねる
- **開口度メーター**と目標値、到達回数の自動カウント
- **ST指導／自主練習**の2モード
- **管理番号ごと**の目標プリセット・練習ログ保存（個人情報は扱わない）

## 動かし方

カメラは**セキュアコンテキスト（https もしくは `http://localhost`）**でのみ動作します。
`index.html` をファイルとして直接開くとカメラが使えないため、ローカルサーバ経由で開きます。

ビルドや `npm install` は不要です（React・MediaPipe を import map で CDN から読み込みます）。

```bash
# このリポジトリのルートで、いずれか1つを実行
python3 -m http.server 8000
# または:  npx serve .   /   php -S localhost:8000
```

ブラウザで <http://localhost:8000> を開き、カメラの使用を許可してください。
初回は MediaPipe のモデル/WASM をネットワークから取得するため数秒かかります。

### 推奨環境

- 端末：スマートフォン／タブレット／PC（インカメラ）
- ブラウザ：最新の Chrome / Edge / Safari
- ネットワーク：初回ロード時に CDN（esm.sh, jsDelivr, Google Storage）へ接続可能なこと

## 使い方の流れ

1. 左パネルで **管理番号**を追加し、患者を選択（記録に必要。練習だけなら未選択でも可）。
2. **ST指導モード**で、ペン／スタンプで目標を描く・「今の口元を目標に」でシャドウを撮影・
   「今の開きを目標に」で開口度目標を設定。必要なら**この目標を保存**。
3. **自主練習モード**に切り替え、保存した目標を**読込**。「練習をはじめる」で到達回数を
   カウント、「終了して記録する」でセッションを保存。

## ファイル構成

```
index.html            … エントリ（import map で依存を CDN ロード）
styles.css            … スタイル
src/
  main.js             … React のブートストラップ
  App.js              … 画面・UI（ST指導／自主練習、患者パネル、ツール）
  html.js             … htm を React にバインド（JSX 風記法、ビルド不要）
  mouthEngine.js      … 口元安定化・オーバーレイ・シャドウ・開口度のエンジン
  faceLandmarker.js   … MediaPipe FaceLandmarker ラッパ
  store.js            … 患者ごとの記録（localStorage）
proposal.md           … 企画提案ドキュメント
```

## 制約・注意

- これはプロトタイプです。保存はブラウザの localStorage（端末ローカル）に限られます。
- 開口度などの指標は相対値で、臨床的な絶対基準ではありません。
- 診断・治療効果を標榜するものではありません（訓練・記録の補助ツール）。
- 実運用に向けては、データ保護、医療機器該当性（薬機法）、院内規程との整合の検討が必要です。
